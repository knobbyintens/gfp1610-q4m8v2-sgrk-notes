# SGRK Reading Notes

Personal reading notes for **Sparse-Gated Recurrent Kernels for Long-Horizon Sequence Modeling**
(preprint ID **2601.01234**, Vasquez et al., January 2026).

Contents:

* summary of the kernel sparsity gate and the temperature-annealed estimator
* notes on the horizon-decay schedule and its learned half-life
* experiment table transcribed from Section 3

There is **no implementation code** in this repository. It is a notes-only
companion and does not run any model.
